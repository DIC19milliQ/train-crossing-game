# Train Crossing Game

HTML、CSS、JavaScriptだけで動く、GitHub Pages向けの静的ブラウザゲームです。

## ゲーム概要

電車を選び、踏切や線路の近くに人・動物・障害物がいるときは電車を止めて、安全になったら進みます。5つのステージを安全に進むとクリアです。

## 遊び方

1. `でんしゃをえらぶ` を押します。
2. 好きな電車を選びます。
3. `スタート` を押します。
4. 危険なときはメインボタンで止まります。
5. 安全になったら同じボタンで進みます。

## 操作方法

- 画面下の大きなボタン: 状況に応じて `とまる` / `すすむ`
- Spaceキー: メイン操作
- Enterキー / 右矢印キー: 補助操作
- `おと ON/OFF`: BGMと効果音の切り替え

## 使用技術

- HTML
- CSS
- JavaScript
- Web Audio API

## 公開について

このゲームは外部ライブラリやビルド環境を使わない静的サイトです。GitHub Pagesでそのまま公開できます。
